# CLAUDE.md

This is the Android port of [Punchboard](https://github.com/QuackByte/punchboard)
(Electron/React desktop app). The desktop repo is the source of truth for the
data format and the hour/pay maths: when porting or changing logic, port its
tests too, and keep the two apps giving the same numbers.

## Data compatibility

The phone reads and writes the desktop's `punchboard.json` as-is, and can
sync with the same file. Never change key formats (zero-based month in day
keys), never drop `"end": null` on running sessions, and keep
`DataFileCodec`'s unknown-field preservation and `JsonMerge` working. Add a
round-trip test for any new field.

## Design

The UI follows the desktop's design (design "A"): the colour tokens in
`ui/theme/Theme.kt` are the desktop's, in light and dark. Prefer the shared
pieces in `ui/components` over ad-hoc styling.

## Documentation and releases

Releases and `CHANGELOG.md` are generated by release-please from
conventional commits (`feat:`, `fix:`, …), as on the desktop. When a PR
adds, changes, or removes a user-facing feature, update **README.md**'s
Features section so it describes what the app does *now*, and record
deliberate divergences from the desktop with the reason.

## Strings

English only for now: UI text is written inline in Compose. Translations
are planned for v1.1, which will move it into `res/values/strings.xml`.
Notification, widget and tile text already lives there.

## Build constraints

AGP 9 builds this project. `app/build.gradle.kts` applies
`android.application`, `kotlin.compose` and `kotlin.serialization` — under
AGP 9 the `kotlin.android` plugin must not be applied alongside them.
